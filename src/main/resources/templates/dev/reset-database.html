Reset Entire Database

This is a developer-only tool. It is not linked from anywhere in the app UI — you reached it by typing the URL directly, and it only exists at all because this app is currently running with the dev profile active.

This will permanently delete every user (including all HR accounts), every leave request, and every audit record. There is no undo. You will need to visit /hrsignup afterward to create a brand-new HR account.
